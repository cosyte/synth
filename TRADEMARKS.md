# Trademarks

`@cosyte/synth` is an independent open-source project. Cosyte is **not affiliated with, endorsed
by, or sponsored by** any standards body or company named in this repository or its documentation.

## Why these names appear

This package generates fixtures in published healthcare data standards, draws codes from published
code systems, and compares itself with another synthetic-data tool. It cannot say what it generates
without naming them.

Every reference is **descriptive**: it identifies a standard, a code system, or a product, and
nothing more.
